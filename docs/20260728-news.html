1inch Launches Aqua Shared Liquidity Protocol
Decentralized exchange aggregator 1inch officially launched shared liquidity protocol Aqua for all users. Aqua allows users to support multiple liquidity positions with one token balance without depositing assets into liquidity pools, with assets remaining in user wallets. Only when trades actually execute does the protocol call corresponding tokens from wallets through single atomic transactions to complete settlement. This "shared liquidity" model addresses long-term DeFi liquidity issues.
