AI Coding Agents Struggle with Codebase Migration: Only 5.4% Pass All Tests
Einsia released SWE Refactor Bench, specifically testing whether Coding Agents can independently migrate entire codebases. Twenty tasks from real projects like SQLite, zlib, libsodium, and GraphHopper include migrations such as C to Rust, Maven to Gradle, and SQLite to WASI, with each task given 6-30 hours. Eight frontier models with 26 configurations ran 520 attempts total. Only 28 attempts fully passed all checks—a 5.4% success rate—and 13 of 20 tasks had zero successful completions. Current Coding Agents can handle large-scale code changes but are far from achieving "entire system migration with zero errors."
